# Ginnie Theme

## CC10X Plugin

Use the **cc10x** plugin for all development tasks. Invoke via `/cc10x` or let it auto-trigger on development keywords.

**Available workflows:**
- Code generation and implementation
- Code review and auditing
- Debugging and bug investigation
- Planning and architecture
- Test-driven development
- Frontend and backend patterns
- Session memory management
- GitHub research

**Trigger keywords:** build, implement, create, review, debug, fix, plan, test, refactor, optimize, feature, component, api, etc.
