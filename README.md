# Ginnie Theme

A simple and clean theme for Home Assistant, based on the default theme with a touch of green.

## Features

*   A familiar look and feel, based on the default Home Assistant theme.
*   Green accents for a fresh and modern look.
*   Supports both light and dark modes.

## Installation

This theme can be installed via HACS.

1.  Go to HACS > Frontend > Themes.
2.  Search for "Ginnie Theme" and install it.
3.  Restart Home Assistant.
4.  Select the "Ginnie Default" theme in your user profile.
